# JavaScript Practice Problems

This repository contains 10 JavaScript practice problems with solutions. Each file can be run independently using Node.js.

## Prerequisites

Make sure you have Node.js installed on your system. You can download it from [nodejs.org](https://nodejs.org/).

## How to Run

Each JavaScript file can be executed using the `node` command followed by the filename. Here are the terminal commands for each problem:

### Problem 1: Reverse a String

```bash
node 01-reverseAString.js
```

**Description:** Write a function that takes a string and returns it reversed.

### Problem 2: Count Vowels in a String

```bash
node 02-countVowels.js
```

**Description:** Write a function that counts how many vowels (a, e, i, o, u) are in a given string.

### Problem 3: Check for Palindrome

```bash
node 03-checkPalindrome.js
```

**Description:** Write a function that checks if a string is a palindrome (reads the same forward and backward).

### Problem 4: Find Maximum Number

```bash
node 04-findMaxNumber.js
```

**Description:** Write a function that finds the maximum number in an array.

### Problem 5: Remove Duplicates

```bash
node 05-removeDuplicates.js
```

**Description:** Write a function that removes duplicate elements from an array.

### Problem 6: Sum of All Numbers

```bash
node 06-sumOfAllNumbers.js
```

**Description:** Write a function that calculates the sum of all numbers in an array.

### Problem 7: Find Even Numbers

```bash
node 07-findEvens.js
```

**Description:** Write a function that finds all even numbers in an array.

### Problem 8: Capitalize First Letter

```bash
node 08-capitalizeFirstLetter.js
```

**Description:** Write a function that capitalizes the first letter of each word in a string.

### Problem 9: Factorial of a Number

```bash
node 09-factorialOfNumber.js
```

**Description:** Write a function that calculates the factorial of a given number.

### Problem 10: Ping Pong Challenge

```bash
node 10-pingPongChallenge.js
```

**Description:** Write a function that implements a ping pong challenge logic.

## Running All Files

To run all files sequentially, you can use the following commands:

```bash
node 01-reverseAString.js
node 02-countVowels.js
node 03-checkPalindrome.js
node 04-findMaxNumber.js
node 05-removeDuplicates.js
node 06-sumOfAllNumbers.js
node 07-findEvens.js
node 08-capitalizeFirstLetter.js
node 09-factorialOfNumber.js
node 10-pingPongChallenge.js
```

## Notes

- Each file contains example inputs and expected outputs in the comments
- The functions are already implemented and will display results when run
- Make sure you're in the correct directory when running the commands
